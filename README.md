
# Visual Code Flow Tracker

An interactive Python tool designed to analyze source code structure and generate visual control flow diagrams, making complex logic easier to understand, debug, and document.

## Features
- **Static Code Analysis:** Uses Python's built-in `ast` (Abstract Syntax Tree) module to parse and analyze code structure accurately.
- **Visual Flowcharts:** Generates clear execution flow diagrams using `Graphviz`.
- **Interactive Web Interface:** Built with `Streamlit` for a smooth, user-friendly experience.
- **Google Colab Ready:** Can be run directly in the cloud with zero local setup required.

## Tech Stack
- **Language:** Python 3
- **Core Libraries:** `ast`, `graphviz`, `streamlit`
